# Adult Income Prediction Project

Group project for the Supervised Learning & Model Engineering course at Albert School (2026).

We use the Adult / Census Income dataset from OpenML (fetch_openml(name="adult", version=2)). Each row is a person from the 1994 US census, and the goal is to predict if this person earns more than 50K dollars per year using information like age, education, occupation or hours worked per week.

It's a binary classification problem and the classes are imbalanced, only around 24% of the people earn more than 50K.
