**Course:** Supervised Learning & Model Engineering
**Teacher:** Ilana Sebag
**Team:** Thomas Pasquier--Guillard, Robin Cacarié et  Lélia Hervy

**Author of Dataset:** Ronny Kohavi and Barry Becker, "Scaling Up the Accuracy of Naive-Bayes Classifiers: a Decision-Tree Hybrid", Proceedings of the Second International Conference on Knowledge Discovery and Data Mining, 1996

## Our choosen problem

We play the role of a **government pay-equity regulator**. Our question is whether people are paid fairly with respect to **sex and race**, under the principle of **"equal pay for equal work"**.

We train a **reference pay model** that predicts the probability of earning more than \$50K **from job-related factors only**:
- age, education, occupation, working hours, workclass and investment income are used;
- sex, race and native country are never used, and neither are their proxies (marital status and relationship).

For each group, the audit then compares:
- the **actual** share of high earners;
- the share the model **expects** from the group's qualifications.

A significantly negative **unexplained gap** is a reason to open an investigation. It is not a proof of discrimination.

## Main results (test set, 9,769 people)

| | Result |
|---|---|
| Final model | LightGBM tuned with Optuna, isotonic calibration, threshold 0.5 |
| Performance | ROC-AUC 0.893, average precision 0.777, precision 0.82, recall 0.50 |
| Calibration | Expected calibration error 0.009 (0.135 before calibration) |
| Unexplained gap, women | **−5.4 points** (95% CI −6.3 to −4.6) |
| Unexplained gap, Black employees | **−3.4 points** (95% CI −4.9 to −1.9) |
| Model trained on all columns, sex and race included | Gap ≈ 0 for every group: it learns the discrimination and hides it |

The written report gives the full analysis and how we justify each choice.

## How to run

Run the steps in order from the repository root. Each step saves what the next one needs.

```bash
python -m src.train        # baseline, imbalance remedies, 3-model comparison      (~1 min)
python -m src.tune         # hyperparameter tuning with Optuna                       (~15–20 min)
python -m src.calibrate    # calibration, threshold, final evaluation on the test set
python -m src.explain      # SHAP figures
python -m src.audit        # fairness metrics, pay-equity audit, mitigation, sensitivity
python -m src.export       # writes serving/audit_model.pkl and serving/model_info.json
```

Every run is logged in **MLflow**, in the experiment `adult-pay-equity`. To browse the parameters, metrics, figures and saved models:

```bash
mlflow ui --backend-store-uri sqlite:///mlflow/mlflow.db
```

Then open http://127.0.0.1:5000.

### The audit API

```bash
cd serving
uvicorn audit_api:app --reload
```

Open http://127.0.0.1:8000/docs to try the endpoints:

| Endpoint | What it returns |
|---|---|
| `GET /health` | Service status, model name and threshold |
| `POST /predict` | Expected probability of earning >50K for each employee |
| `POST /audit` | For each sex and race group: actual vs expected rate, unexplained gap with a 95% CI, potentially underpaid employees |

Sex and race are only used to **group** the audit results. The model drops them before predicting.

## Methodology in short

1. **Split:** 60% train, 20% validation, 20% test, stratified, with `random_state=42`. The test set is used once, at the end.
2. **Features:**
   - protected attributes, their proxies, `fnlwgt` and `education` (a duplicate of `education-num`) are dropped inside the pipeline;
   - five features are added: `capital_net`, `has_capital`, `log_capital_gain`, `works_overtime`, `is_part_time`.
3. **Class imbalance (24% positives):** we use `class_weight="balanced"`, after comparing it with undersampling and SMOTE.
4. **Models:** Logistic Regression, Random Forest and LightGBM, all in one scikit-learn `Pipeline`.
5. **Tuning:** Optuna (TPE, seed 42) with 5-fold stratified cross-validation on the training set, optimising average precision.
6. **Calibration:** `CalibratedClassifierCV(cv=5)`. Isotonic is chosen over sigmoid on Brier score and ECE.
7. **Explainability:** SHAP `TreeExplainer`, with global and individual explanations.
8. **Fairness:**
   - fairlearn `MetricFrame`: demographic parity, equal opportunity, equalized odds;
   - pay-equity audit with bootstrap confidence intervals;
   - before/after comparison of the mitigation (pre-processing);
   - proxy check;
   - sensitivity check without the capital columns.

## Limitations

- **Unexplained is not proven.** Unobserved factors (seniority, exact job, region, performance) could explain part of a gap.
- **Some discrimination is invisible to the audit.** Unequal access to well-paid jobs is "explained" by occupation and hidden, so the measured gaps are a lower bound.
- **The data describes individuals, not companies,** and dates from 1994. The target is total income above \$50K, not salary. The method matters more than the size of the gaps.
- **Small race groups** (Amer-Indian-Eskimo, Other) have too few people for conclusions.

## Reproducibility

- All random steps use `random_state=42`: the split, the models, Optuna, cross-validation and the bootstrap.
- Re-running the pipeline reproduces the reported numbers.
